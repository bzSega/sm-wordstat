# sm-wordstat — Yandex Wordstat API

## Назначение

Статистика поисковых запросов Яндекса: топ, динамика, регионы. Без браузера и капчи.

## Когда использовать

- SEO-семантика: собрать ядро запросов
- Анализ спроса: динамика по месяцам
- Региональное распределение: где ищут больше
- Конкурентный анализ: частоты по запросам

## Установка

### 1. Получить ключ Yandex Cloud

1. Зарегистрируйтесь в [Yandex Cloud](https://cloud.yandex.ru)
2. Создайте каталог (folder) — запомните `FOLDER_ID`
3. Включите сервис **Search API** в каталоге
4. Создайте API-ключ: `Сервисные аккаунты → Создать → API-ключ`
5. Запомните `API_KEY`

### 2. Установить переменные окружения

```bash
export WORDSTAT_API_KEY="ваш_ключ"
export WORDSTAT_FOLDER_ID="ваш_folder_id"
```

### 3. Проверить

```bash
python skills/sm-wordstat/scripts/wordstat.py top "песня на 1 сентября"
```

## Команды

### Топ запросов

```bash
python wordstat.py top "песня на 1 сентября" --limit 30
```

Возвращает список поисковых фраз с частотами показов.

### Динамика по месяцам

```bash
python wordstat.py dynamics "песня на 1 сентября" --from 2026-01 --to 2026-09
```

Возвращает частоту запроса по месяцам.

### Распределение по регионам

```bash
python wordstat.py regions "песня на 1 сентября"
```

Возвращает частоту запроса по регионам России.

## Параметры

- `--limit N` — количество фраз (по умолчанию 50)
- `--from YYYY-MM` — начало периода (для dynamics)
- `--to YYYY-MM` — конец периода (для dynamics)
- `--region ID` — регион (по умолчанию 225 = Россия)

## Скрипт

Готовый Python-скрипт: `scripts/wordstat.py`. Не требует установки зависимостей — только стандартная библиотека Python 3.10+.

## Ценность

- **SEO-оптимизация** — собрать семантику для контент-плана
- **Анализ спроса** — понять сезонность и тренды
- **Региональный маркетинг** — где искать аудиторию
- **Конкурентный анализ** — частоты по брендовым запросам

## Антипаттерны

- Не запрашивать больше 30 фраз за раз — API возвращает максимум 50
- Не забывать `--from` и `--to` для dynamics — без них вернёт ошибку
- Не использовать `args.from` в Python — `from` зарезервированное слово, используйте `getattr(args, "from")`
